# Zoo Bauru 3D - TCC Project

## Project Type

This is a 3D visualization thesis (TCC), not a typical codebase. No build, test, or lint commands exist.

## Stack

- **Blender** - 3D modeling
- **Blend4web** - HTML export from .blend files
- **HTML** - Web exports in `Blender/web/`

## Structure

- `Blender/` - Source .blend 3D files
- `Blender/web/` - Exported HTML (deployed to Vercel)
- `imagens/` - Screenshots
- `*.pdf` - Thesis document

## View Live

https://zoobauru.vercel.app/

## No Dev Commands

No npm/node, no build scripts, no tests.
